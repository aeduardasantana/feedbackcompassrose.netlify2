Portal estático provisório da consultora Ruth e do Grupo Bemec.
Sem Supabase, Netlify, APIs ou serviços recorrentes.
index.html — home da consultora com créditos e atalhos;
formulario.html?avaliacao=023 (ou 024,025) — acesso separado para respondentes;
status.html?avaliacao=023 (ou 024,025) — relatório de status separado.
Atualizar manualmente o arquivo dados.js após conferir a planilha de controle.
Os links de formulário e status permanecem vazios até serem informados; não simular respostas.
Para publicar na Locaweb, copie a pasta avaliacoes/ruth/ inteira para a pasta-raiz do domínio em operação.
ATENÇÃO: este conteúdo estático NÃO tem autenticação real. É inadequado para dados confidenciais.
O caminho é apenas estrutural; a URL pública depende do deploy da Locaweb.
